# Community code of conduct

GymTS welcomes users, researchers, and contributors with different backgrounds and experience. We aim to discuss problems clearly, make results verifiable, and let participants collaborate safely. This code applies to project Issues, PRs, code reviews, and project-organized discussions.

When participating:

- Respect others. Critique designs and evidence rather than judging personal ability, identity, or motives.
- Provide reproducible information and explain limitations. Be patient when correcting mistakes, and accept correction yourself.
- Respect privacy, copyright, and data-use permissions. Obtain authorization before sharing conversations, logs, or other people’s contact details.
- Avoid harassment, threats, discrimination, insults, persistent personal attacks, unsolicited private-message harassment, and disclosure of personal information.
- Follow reasonable maintainer requests intended to end conflict, protect participants, or keep discussion on topic.

Request maintainer intervention in the relevant discussion if misconduct occurs. For private matters, first make a [channel request](https://github.com/Jurmean/GymTS/issues/new) without personal information or incident details, then provide materials after a maintainer confirms a private channel. The project has not designated a public dedicated conduct contact or confidential response service; do not publish victims’ identities or private evidence. Follow the [security reporting process](SECURITY.md) for software vulnerabilities.

Maintainers with repository administration rights may request edits, close or lock discussions, remove inappropriate content, and restrict participation when necessary. Responses should consider the behavior, impact, and repetition; maintainers are also subject to this code. Reporters may request review by another authorized maintainer, but the project does not guarantee independent arbitration personnel or fixed response times.

This code was written for GymTS and does not claim membership in any third-party governance or certification program.
