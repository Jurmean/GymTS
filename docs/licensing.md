# MIT 许可证与第三方边界

GymTS 采用 **MIT License**，完整许可、版权及免责条款见根目录 [LICENSE](../LICENSE)。
本仓库的框架代码、独立适配包、教学示例和文档采用该许可；明确另行标注的第三方
内容保留其原有条款。分发时保留相应版权和许可声明，以 `LICENSE` 原文为准。

## 不同交付物分别授权

GymTS 的 MIT 许可不会重新授权所调用的外部项目、模型权重、数据集、二进制或用户
附件。安装适配包、调用服务或转换格式，不会改变这些资产的许可和用途限制。
五份既有 benchmark 附件继续是 evaluation-only，不能因框架采用 MIT 而用于训练
或未经来源授权公开分发。

[第三方来源清单](../THIRD_PARTY.md)提供逐项目、数据和权重的审核入口。实际分发
第三方内容时，仍需核对精确版本的 LICENSE、NOTICE、Dataset / Model Card，并保留
上游要求的归属与其他声明。此清单不等于已经完成全部第三方许可兼容性审计。

## 维护与发行

核心和独立适配包的元数据、源码包及 wheel 应声明 MIT 并包含对应许可文本。
`CITATION.cff` 记录软件许可和版本；引用不替代许可声明。打包与检查步骤见
[维护指南](maintainer-guide.md)。历史验收报告保留当时的许可状态与制品摘要，
不为反映本次选择而重写；采用 MIT 也不表示已经创建 Git 标签或发布到包索引。

本次许可文本、发行元数据与制品校验见[MIT 最终验证摘要](reports/mit-license-2026-10-20.json)。
