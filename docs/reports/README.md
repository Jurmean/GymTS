本机路径和原始日志 SHA256 用于标识当时的证据，不表示相应资产已经公开发布。

题目或答案的审计文件不随源码分发。复现请使用各适配包的正式示例，并在本机生成
新的运行记录。历史摘要保持原有事实；源码整理不会改写既有实验结果或制品身份。
